## 🛠 Технологии
Проект написан **без использования сторонних библиотек** и фреймворков:
*   **HTML5** (семантическая, валидная разметка)
*   **CSS3** (CSS Grid, Flexbox, CSS Variables, Media Queries)
*   **Vanilla JavaScript** (ES6+, IntersectionObserver, DOM API)
*   **Google Fonts** (системные шрифты и моноширинные акценты)

## ✨ Особенности и функционал

**Дизайн и верстка:**
*   **Строгий адаптив:** Сетки перестраиваются от 4 колонок на ПК до 1 колонки на мобильных устройствах.
*   **Минимализм:** Использование тонких рамок, моноширинного шрифта для технических подписей и мягкой цветовой палитры.
*   **CSS-переменные:** Все цвета, отступы и шрифты вынесены в `:root` для легкой поддержки и изменения темы.

**JavaScript (Интерактивность):**
*   **Мобильное меню:** Бургер-меню, которое плавно открывает навигацию на смартфонах и закрывается при клике на ссылку.
*   **Анимация при скролле:** Секции плавно выезжают снизу при прокрутке страницы (реализовано через `IntersectionObserver`).
*   **Активный пункт меню:** При скролле текущая секция автоматически подсвечивается в шапке сайта.
*   **UX-фишки:** При клике на карточки контактов (Email, Telegram, GitHub) появляется всплывающее уведомление (Toast).
